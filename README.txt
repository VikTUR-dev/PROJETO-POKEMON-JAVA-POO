# 🎮 PROJETO POKEMON - JAVA POO

## 📌 Sobre o projeto

Projeto acadêmico desenvolvido em **Java**, inspirado no universo Pokémon, com foco na aplicação de conceitos de **Programação Orientada a Objetos (POO)**.

## 🎯 Objetivo

Desenvolver um jogo com sistemas de **batalha, captura, Pokédex e evolução**, aplicando conceitos de Java e POO.

## 🛠️ Tecnologias utilizadas

* Java - Programação Orientada a Objetos (POO)
* Git e GitHub

## 📂 Estrutura do projeto

O projeto é organizado em classes responsáveis pelos Pokémon, batalhas, Pokédex, menus e execução do jogo.

## ⚙️ Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE Java.
3. Configure o JDK.
4. Execute a classe principal (`App`).

## 🎮 Como utilizar

O jogador escolhe seu treinador e Pokémon, enfrenta Pokémon selvagens, podendo **atacar ou tentar capturá-los**. Após a batalha, pode batalhar novamente, consultar a Pokédex ou sair.

## 📋 Funcionalidades

* Escolha do treinador
* Visualização da Pokédex
* Captura de Pokémon
* Batalhas entre Pokémon
* Sistema de vantagem entre tipos
* Cálculo de dano
* Sistema de nível
* Sistema de velocidade
* Ataques específicos para cada tipo
* Evolução por nível
* Menu de interação no terminal
